# 操作系统基础

???+ tip "老司机"
    如果您有过折腾Windows PE或者黑苹果的经历，您大可跳过该节。

本节我们会介绍一些操作系统 (Operating System, 简称OS) 的基本概念。尽管您在使用Windows时可能不需要了解这些概念，但这是安装其他任何操作系统（不单单是Linux）的必备知识。

这篇文章不会涵盖操作系统的全部知识，但对于安装新系统来说足矣。

## 底层

### BIOS

英文：Basic Input/Output System（BIOS）

BIOS（基本输入输出系统）是操作系统与计算机硬件之间的桥梁，为计算机提供基本的输入输出接口。

在之前，您可能听说过在解决部分电脑问题时需要进入BIOS调设置。然而，BIOS是计算机的敏感地带，随意调节任何一个设置都有可能导致安全性降低或者系统不能正常工作。所以，在调节BIOS设置时，请一定首先阅读BIOS底部所提供的快捷键。在调节选项前，请一定提前了解选项对应的含义或者询问AI。

### UEFI

英文：Unified Extensible Firmware Interface（UEFI）

UEFI（统一可扩展固件接口）是基于BIOS的衍生替代方案，其作用主要来定义操作系统与系统固件之间的软件界面，作为BIOS的替代方案。可扩展固件接口负责联系操作系统以及提供连接操作系统与硬件的固件层产品。

目前，统一可扩展固件接口（UEFI）正在逐步取代旧式BIOS，但仍有很多产品支持兼容模式，通过Legacy选项，但类似这种的支持逐渐减少。目前，UEFI与兼容支持模式（CSM）成为主流，但最新的产品已经不再支持兼容模式，仅支持UEFI。 

???+ note "如何选择？"
    在支持且无严重Bug的情况下请选择UEFI，更加现代，安全，快速。如果不支持或存在严重bug的情况下选择BIOS。

#### 安全启动

安全启动是UEFI的安全功能，用于保护引导组件不被篡改。安全启动需要经过签名的EFI文件来运作。我们将在下文提到EFI的作用。

安全启动可以在BIOS设置中开启或关闭。

## 引导

英文：Boot Loader

在开机时，计算机并不是直接启动操作系统，而是要先经过BIOS与引导。

引导是计算机启动时，BIOS/UEFI用来寻找并启动操作系统的程序。通常情况下，引导文件为EFI格式，并统一存储在ESP分区（一般来说是磁盘分区图最靠左的不大的FAT32分区）中。我们会在下文提到分区的概念。

大多数Linux发行版使用GRUB作为引导。要美化引导，请参阅[引导美化](../advanced/boot_loader.md)。

???+ note "一般ESP分区的结构"
    **ESP目录结构可能因挂载点不同存在差异，请自行替换下方教程路径。**

    ```
    /boot/efi/EFI
    ├── BOOT
    ├── fedora
    │   └── ...
    └── Microsoft
         └── Boot
               └─ ...

    ```

## 存储

我们知道，操作系统存储于硬盘中，但是，如何使不同的操作系统并存在硬盘中呢？

### 分区

英文：Partition

硬盘分区是使用分区软件（比如DiskGenius，Windows的磁盘管理等等等等）在磁盘上划分几个逻辑部分，也就是一块盘上的多个分区，如C盘与D盘的区别。

简单来说，分区就是在单块/多块磁盘上划分出不同的数据存储区域，这些区域可以有不同的文件系统，相互独立。所以通过为不同操作系统分区，我们能够使得不同的操作系统并存而不会相互造成影响。

在访问分区时，操作系统通常需要先挂载这个分区。这一过程在Windows上会自动进行，但在Linux上并不一定。

???+note "关于分区连续性"
    一般情况下，分区都是**连续的**，因此调整分区时需注意分区的的顺序位置，来回调整分区极易造成**数据损坏！！！**

### 文件系统

英文：File System

文件系统是一种存储和组织计算机数据（如txt文件）的方法，它使得对存储设备（如硬盘、U盘）访问和查找变得容易，文件系统使用文件和目录的抽象高级概念代替了硬盘和光盘等物理设备使用数据块的概念，就像油画和照片的区别，不同的文件系统可以理解为不同的画派。

不同的分区可以具有不同的文件系统，不同操作系统对文件系统的支持也不同，比如Windows不支持读写Ext4，而Linux对NTFS的支持不够完善。

???+ example "常见的文件系统"
    - Ext3 (Linux可用，已基本废弃)
    - Ext4 (Linux常用，推荐使用)
    - Btrfs (Linux可用，有众多高级特性，但不建议新手涉足)
    - NTFS (Windows常用，Linux上仅可挂载读写)
    - Xfs (Linux常用，大文件传输优化，不支持缩容)

???+ note "扩展：磁盘分区表"
    英文：Disk Partition Table

    磁盘分区表是记录硬盘分区信息的数据结构。目前主流的分区表格式有两种：传统的老式 MBR 和现代通用的 GPT。选择哪种分区表直接决定了您能使用的最大硬盘容量以及支持的分区数量。

    - **MBR**：传统方案，仅支持4个主分区（或3主+1扩展），最大2TB容量，易受限制，适用于旧系统（Windows 7 前使用）。
    - **GPT**：现代标准，支持128个分区，容量可达18EB，兼容UEFI引导，数据更安全（冗余分区表），适合大容量硬盘和新系统。

    ???+ note "如何选择？"
        目前在UEFI工况下，闭眼选GPT即可，如果你的机器不支持UEFI，请选择MBR分区表
