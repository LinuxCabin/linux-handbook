# XFCE

![xfce](https://wiki.xfce.org/_media/xfce-64x64.png)

[官网](https://www.xfce.org/)

[官方文档](https://docs.xfce.org/)

## 概述

Xfce是一个轻量级的[桌面环境](../desktop.md#_2)，Xfce 有着快速、轻便、易于使用的优点，Xfce开机占用的内存大约只有700M，Xfce一开始使用X11显示协议，自从4.20版本开始提供了实验性的Wayland支持。

## 安装

- Debian系列：`sudo apt install xfce4`
- 红帽系：`sudo dnf install xfce4`
- Arch系：`sudo pacman -S xfce4`

## 配置

您可以在开始菜单里打开设置管理器配置字体与图标，您可以在桌面空白处右键选择桌面设置配置壁纸，Xfce的大多数设置都可以在图形化的设置界面中完成修改。
