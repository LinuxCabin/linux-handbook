# WPS Office

WPS Office是金山办公的国产办公套件，含文字、表格、演示等组件，支持多平台与云端协作。WPS 365是其企业级一站式AI协同办公平台，整合办公、协作与AI能力。

## 安装

### WPS Office

- [官网](https://www.wps.cn/product/wpslinux): 提供`deb`与`rpm`格式安装包
- AUR: `yay -S wps-office-cn`
- [Flatpak版本](https://flathub.org/zh-Hans/apps/com.wps.Office): `sudo flatpak install com.wps.Office`

### WPS 365

- [官网](https://365.wps.cn/download365): 提供`deb`格式安装包
- AUR: `yay -S wps-office-365`
- [Flatpak版本](https://flathub.org/zh-Hans/apps/cn.wps.wps_365): `sudo flatpak install cn.wps.wps_365`
