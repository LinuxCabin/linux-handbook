# FreeCAD

![freecad](https://www.freecad.org/svg/logo-freecad.svg)

## 概述

`FreeCAD`是一款开源的通用参数化三维CAD建模软件，其许可协议遵循LGPL许可。支持2D草图、3D建模、CAM、BIM等功能，需要一定基础知识。

## 安装

Debian系：
```bash
sudo apt install freecad
```

红帽系：
```bash
sudo dnf install freecad
```

Arch系：
```bash
sudo pacman -S freecad
```

## 使用

鉴于本文档的通用性，在此仅给出简单实现以供参考。

### 初始化

安装启动后，应用会弹出配置窗口。在Language项选中中文，单位按需选择后点击完成，再重启应用即可。

### 快速上手

在工具栏中，有`Part Design`下拉列表，选中即可进行不同工作台之间的切换。

选择相应工作台后新建文件即可开始编辑。默认状态下，右侧有任务窗口供下一步参考。
