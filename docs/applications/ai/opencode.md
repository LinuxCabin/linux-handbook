# OpenCode

## 概述

[opencode](https://opencode.ai)是一个开源的Claude Code替代品，内置丰富的免费AI模型，可以帮你写代码、处理文档、整理文件，从而提高你的工作效率。

## 安装

OpenCode提供了CLI和桌面版。

### CLI版
打开系统自带的终端模拟器，输入以下指令:

```bash
curl -fsSL https://opencode.ai/install | bash 
```

### 桌面版

桌面版直接在[OpenCode下载页面](https://opencode.ai/download)选择桌面版下载。

其余安装方式参照[OpenCode官方文档](https://opencode.ai/docs/zh-cn)。

## 使用

打开终端模拟器，输入：
```bash
opencode
```

以此启动OpenCode。

如果你无法启动，通常登出一下问题就会解决，如果登出依然无法解决，可能是因为你更改了默认Shell，可以重新通过命令安装或者上网检索如何修改你使用的Shell的环境变量。

具体方法参照[OpenCode官方文档](https://opencode.ai/docs/zh-cn)。
