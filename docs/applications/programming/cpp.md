# C++开发套件

## g++

### 概述

g++是GNU项目开发的C++编译器，属于GNU编译器套件（GCC）的核心组成部分。它通过命令行运行，能把C++源代码文件编译、链接并转换成计算机可以直接运行的二进制可执行程序。

### 安装

- Debian 系(Ubuntu, Mint, Debian)

```bash
sudo apt install g++ -y
```

- 红帽系(Fedora, rhel, rocky)

```bash
sudo dnf install g++ -y
```

- Arch系

```bash
sudo pacman -S g++ -y
```

### 使用

请参考`man g++`。
