# GParted

![GParted](https://gparted.org/images/gparted-64x42.png)

## 概述

GNOME Paradition Editor（简称GParted）是图形化环境下易于编辑分区的维护软件，另有LiveCD用于系统维护。

GParted是[自由软件](https://www.gnu.org/philosophy/free-sw.html)，基于[GPL-2.0](https://www.gnu.org/licenses/old-licenses/gpl-2.0.html)发布。

!!! warning "警告"
    **数据无价，谨慎操作**

## 安装

由于维护性质软件需要获取高级权限，Gparted并不支持通过Flatpak或Snap进行安装

- Debian系：
    ```bash
    sudo apt install gparted
    ```

- 红帽系：
    ```bash
    sudo dnf install gparted
    ```

- Arch系：
    ```bash
    sudo pacman -S gparted
    ```

## 使用

通过包管理器安装后，需要管理员账户的认证才能启动。

!!! note "提示"
    启动后，您可能会看到文件管理器中的驱动器显示不正常，这是GParted启动时所必须的流程，不必担心。

界面从上到下可概括为三栏：
- 工具栏
- 快捷操作栏
- 分区使用情况

先在工具栏`GParted``设备`选中相应块设备（一般是硬盘）进行操作。

在分区使用情况一栏中，在分区一列带钥匙图标的分区属于“已挂载分区”，部分分区在此状态下允许在线调整大小，其余功能处于灰色/不可用状态。如分区一栏显示黄色感叹号，应右键相应分区选中`信息`查看提示信息。

!!! note "提示"
    在软件外修改分区挂载情况后，建议在工具栏选中`GParted``刷新设备`使GParted同步。

初次使用时建议在上方工具栏中选中`查看``设备信息`，避免操作关键硬盘。

### 文件系统支持

`查看``文件系统支持`中查看目标分区格式的支持状况。如所需操作显示为X，应在包管理器中安装提示给出的软件包并重新扫描支持的操作 。若相应功能仍不可用，请在重启后重试。

### 创建分区表

如您有一块尚未格式化的新设备，需要建立新的分区表以保存分区。在GParted`设备`一栏选中需格式化的设备，再点击`设备``创建分区表` ，选中所需分区表即可。在支持UEFI启动的设备上建议选择gpt，否则建议选择msdos（即mbr）。本操作确定后自动提交，**谨慎操作**。

### 创建、调整、抹除

本案例假定用户系统中存在足够的空闲空间且已有建立的分区表。请在电力供应充足的环境下进行分区操作。

!!! note "提示"
    GParted采用非实时交互，即使误操作也不必慌张，在未提交时点击上方快捷操作栏的黄色箭头即可进行撤回。

先选中灰色的空闲空间，在工具栏选中`分区``新建`创建新分区，右下角选中合适的分区，再在`新大小`一栏输入目标MiB大小即可创建。这里推荐选择Btrfs进行操作，因其在GParted中支持较全面。

!!! note "提示"
    GParted默认将分区采用MiB方式对齐，可能导致部分操作失败或留下奇怪的空余空间。如有需要，更改为`柱面`即可。

选中新创建的分区，选中`分区``调整大小/移动`。此时可以将鼠标指针移动到白色区域中，左右移动来调整分区前后的空闲空间。也可以通过拖拽两端箭头或在`新大小`中输入所需分区大小。调整完毕后，点击右下角`调整大小/移动`完成操作并提交。

现在执行抹除操作。选中所创建的分区，依次点击`分区``删除`。再次确定分区号后点击删除，最后点击提交。此时，分区状况应恢复成调整之前的状况了。

### 跨设备移动分区

如您需要将某分区迁移至另一物理硬盘，选中它，点击`分区``复制`。再在目标硬盘中选中空闲空间，点击`分区``粘贴`完成迁移操作。您可以在新弹出的窗口中移动或扩大分区，完成后点击确定再提交即可。
