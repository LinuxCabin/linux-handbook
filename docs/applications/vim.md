# Vim

## 概述

`vim` 是一款i轻量高效的终端文本编辑器, 几乎所有的Linux发行版都会预装。

第一次使用vim的人，最大的感受一定是: 反人类。
Vim 虽然前期学起来困难, 但是上限极高，一旦熟练你很难接受其他的编辑器(我自己是这样的)。

话虽如此，在终端用Vim改个配置文件依旧是很多Linux玩家的日常
所以我们有必要稍微学习一下如何使用Vim完成以下基础的操作。

---

## 模式

模式是vim中最具特色的概念，我们只需要看编辑器的左下角就可以分别当前的模式
对于新手来说，只需要掌握**三种模式**即可使用vim， 分别是

- **INSERT** -> 插入模式
    - 插入模式下,你可以**直接编辑内容**,在键盘上面打的每一个字都会如实出现在文件中,相当于普通编辑器的模式
    - 当你处于插入模式的时候, **左下角会出现 INSERT**

- **NORMAL** -> 普通模式
    - 普通模式下,不能使用常规的编辑方式修改文件,而是完全使用**vim语法**实现超级快速的**移动和修改**
    - 当你处于普通模式的时候, **左下角是空的**,普通是默认的模式

- **COMMAND** -> 命令模式
    - 命令模式下,我们通过某些简单的命令来**控制编辑器的行为或者控制终端**
    - 当然这个模式也是可以批量处理文本的(比如说替换之类的操作)
    - 当你处于命令模式的时候,**左下角有一个冒号,所有键盘打出来的都会出现在冒号后方,而不是文本中**

---

## 模式的转换

我们可以将 **NORMAL** 视作 vim 模式的中心枢纽。
因为**所有的模式下,按esc键都能变成普通模式**。
并且 普通模式 只需要按一个键就可以切换到各种模式。

所以我们只需要记住下面的内容即可 (对于新手来说)：

当你处于非普通模式的时候:

- Esc (键盘最左上角的键) -> 回到普通模式

当你处于普通模式的时候:

- i -> 进入插入模式
- : -> 进入命令模式(没错这里就是打个冒号)

## 一般流程

- 打开文件

    ```bash
    # 使用 vim 打开你需要编辑的文件
    # 语法是 vim 路径
    vim /path/to/file
    ```

    打开之后就是普通模式。

- 移动

这个时候如果不是空的文件,你一般需要移动
可以直接使用方向键
或者用这个**超人类语法** -> h j k l (分别对应 左 下 上 右 的方向键)


- 进入插入模式进行编辑

    按下 `i` 键, **看到左下角出现INSERT**，然后就是正常的编辑工作

- 保存修改
    我们需要使用命令模式保存修改，所以第一步是先按 Esc 回到普通模式。

    这个时候你会发现左下角的INSERT消失了，

    然后按 `:` 进入命令模式 -> 你会看到左下角出现冒号

    输入 `w` (表示我要将修改写入文件, 也就是 write)

    回车 (这个时候你已经保存了修改)

    输入 `q` (表示我要退出vim, 也就是quit)

    回车

    这个时候你已经成功使用 vim 完成了编辑工作

    > 当然命令模式是可以一次执行多个命令的， 可以直接 `:wq` 表示保存并退出文件
