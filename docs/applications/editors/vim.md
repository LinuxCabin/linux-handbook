# Vim

## 概述

`vim` 是一款轻量高效的终端文本编辑器, 几乎所有的Linux发行版都会预装。

第一次使用vim的人，最大的感受一定是: 反人类。
Vim 虽然前期学起来困难, 但是上限极高，一旦熟练你很难接受其他的编辑器(我自己是这样的)。

话虽如此，在终端用Vim改个配置文件依旧是很多Linux玩家的日常
所以我们有必要稍微学习一下如何使用Vim完成以下基础的操作。

## 安装

Debian系：
```bash
sudo apt install vim
```

红帽系：
```bash
sudo dnf install vim
```

Arch系
```
sudo pacman -S vim
```

## 模式

模式是vim中最具特色的概念，我们只需要看编辑器的左下角就可以分别当前的模式，对于新手来说，只需要掌握**三种模式**即可使用vim， 分别是。

- **INSERT** -> 插入模式

插入模式下,你可以**直接编辑内容**,在键盘上面打的每一个字都会如实出现在文件中,相当于普通编辑器的模式。  
当你处于插入模式的时候, **左下角会出现 INSERT**。

- **NORMAL** -> 普通模式

普通模式下,不能使用常规的编辑方式修改文件,而是完全使用**vim语法**实现超级快速的**移动和修改**。  
当你处于普通模式的时候, **左下角是空的**,普通是默认的模式。

- **COMMAND** -> 命令模式

命令模式下,我们通过某些简单的命令来**控制编辑器的行为或者控制终端**。  
这个模式也是可以批量处理文本的(比如说替换之类的操作),当你处于命令模式的时候,**左下角有一个冒号,所有键盘打出来的都会出现在冒号后方,而不是文本中**。

## 模式的转换

我们可以将 **NORMAL** 视作 vim 模式的中心枢纽。
因为**所有的模式下,按esc键都能变成普通模式**。
并且 普通模式 只需要按一个键就可以切换到各种模式。

所以我们作为基础使用者只需要记住下面的内容即可：

当你处于非普通模式的时候:

- `Esc` 回到普通模式

当你处于普通模式的时候:

- `i` 进入插入模式
- `:` 进入命令模式

## 使用

打开文件
```bash
# 使用 vim 打开你需要编辑的文件
# 语法是 vim 路径
vim /path/to/file
```

打开之后就是普通模式。

移动

- 使用方向键或`h` `j` `k` `j`，对应为上下左右。

保存

- 在COMMAND模式下输入`:w`

退出

- 在COMMAND模式下输入`:q`

强制退出

- 在COMMAND模式下输入`:q!`

保存并退出

- 在COMMAND模式下输入`:wq`
